# Continuity: Demo, how a model learns

Read this before planning a section and add a block after delivering one. It keeps every section of
the video in one visual language: the same colour for the same idea, the same shape for the same
thing, and each section opening where the last one left off.

## Video

- Topic: what "training" an AI model means, in about twenty seconds. It exists to show the whole
  system working: both engines, cue-locked timing, the checks.
- Colour roles (fixed for the whole video): light blue = the question going in; teal = the model's
  settings (its dials); red = the loss, how wrong it is; yellow = the thing to look at, the answer;
  grey = structure.
- Central picture: the model as a box of six dials (`dial_panel(2, 3)`), with a small "model" tag
  under it.
- Recurring shapes: the question as two lines of light blue text ending in a yellow blank; guesses
  as a `bar_list` with bars coloured by their value; the loss as a red number.
- Promises made to the viewer: none.
